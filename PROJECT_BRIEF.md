# Project Brief: Tutifrutsy Website

## Objetivo

Crear un sitio web estatico, informativo y rapido para Tutifrutsy. El sitio busca atraer clientes fisicos al negocio, no vender en linea.

## Reglas principales

- Usar HTML, CSS y JavaScript puro.
- No usar React, Next.js, Astro, Tailwind ni frameworks.
- No incluir carrito.
- No incluir precios.
- No incluir formularios.
- No incluir boton de llamada.
- El CTA principal debe ser "Como llegar".
- No inventar productos no mencionados.
- No inventar otra direccion.
- No abrir sabados.

## Estilo visual

El sitio debe sentirse tropical, fresco, familiar, latino, alegre y local. Debe verse profesional pero no corporativo. Debe sentirse como un negocio real de frutas, minutas y antojitos tropicales.

Colores inspirados en la marca:

- Verde oscuro del logo
- Verde fresco tipo fruta
- Amarillo/mango
- Rojo/fruta/chamoy
- Crema/blanco calido
- Toques de naranja

## Estructura del sitio

1. Header con logo, navegacion simple y boton "Como llegar".
2. Hero con mensaje principal, CTA "Como llegar" y CTA secundario "Ver TikTok".
3. Seccion "Lo mas pedido".
4. Seccion "Que vendemos" por categorias.
5. Seccion de TikTok con 3 videos embebidos.
6. Seccion "Nuestra historia".
7. Seccion "Donde estamos" con direccion, horario, sabado cerrado y mapa/link.
8. Footer con logo, direccion, horario, redes y copyright.
